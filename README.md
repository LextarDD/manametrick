# ManaMetrick

ManaMetrick is a web application designed to track, analyze, and visualize Magic: The Gathering metagames, with a focus on Pauper tournaments and matchup statistics.

## Features

### Metagame Analysis
- Global archetype statistics
- Win rate tracking
- Meta share visualization
- Archetype performance comparison

### Matchup Matrix
- Head-to-head archetype statistics
- Detailed matchup analysis
- Win rate calculations
- Interactive matchup exploration

### Tournament Management
- Tournament creation and management
- Round tracking
- Player registration
- Pairing validation
- Tournament history

### Personal Statistics
- Match history tracking
- Deck performance analysis
- Personal win rate statistics
- Long-term performance monitoring

### Deck Management
- Create and manage decks
- Assign archetypes
- Track deck performance
- Historical deck data
